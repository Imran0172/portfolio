# Imran Sarker | Portfolio Website

Source of **[imransarker.com](https://imransarker.com)**, the personal portfolio of MD. Imran Sarker, Digital Marketer & Web Developer and Founder & CEO of Humble IT Solution.

## About this project

A single-page portfolio built with plain HTML, CSS and JavaScript, with no framework or build step.

- Structured data (Schema.org JSON-LD) for search engines
- `llms.txt` so AI assistants can read a clean summary
- Optimized WebP images

## Files

| Path | Purpose |
|---|---|
| `index.html` | The full website |
| `llms.txt` | Summary for AI assistants |
| `images/` | Portfolio screenshots, profile photo and certificate |

## Run locally

Open `index.html` in a browser.
